┌───────────────────────────────────────────────────────────────────────────┐
│  ⚡ SPEED OPTIMIZATION                                                    │
└───────────────────────────────────────────────────────────────────────────┘

  SKIP DATA FETCHING (Much Faster!)
  ──────────────────────────────────
    In benchmark_config.json:
    {
      "load_previous_plan": 1,
      "load_previous_data": 1
    }

    This makes it test ONLY the LLM analysis/reporting,
    not the data fetching (which is the same for all configs).

    Speed gain: 50-80% faster!

┌───────────────────────────────────────────────────────────────────────────┐
│  🔧 TROUBLESHOOTING                                                       │
└───────────────────────────────────────────────────────────────────────────┘

  "Configuration file not found"
    → Ensure benchmark_config.json exists in project root

  "Timeout after 1 hour"  
    → Use load_previous_plan: 1 and load_previous_data: 1
    → Try smaller/faster models first

  "All configs failing"
    → Check .env file has all API keys
    → Test with quick_test.json first
    → Verify scenario name is correct

  "Inconsistent results"
    → Try lower temperature (0.5-0.7)
    → Check if scenario is well-defined
    → Review if question is too ambiguous
